# Goal

Why this skill exists and what it values. Read before discussing or changing it.

## Why

Skills are how we keep what we learn about working with agents. They change as we use them and as models improve, and they are read by agents that run them, not by people who study them. This skill exists so every other skill stays effective as it changes: the same shape, the same test, the same standard for what earns a line.

## Values

- **A line earns its place by changing behavior.** If the model would do it anyway, the line costs attention and gives nothing back. Fewer, sharper lines beat complete ones.
- **Structure before instruction.** A check the script can make, a slot the output must contain, a noun to enumerate: each of these fires more reliably than a sentence asking for the same thing.
- **Proof comes from a fresh context.** An agent that saw the design cannot tell whether the instruction fires. Real prompts, fresh session, observed behavior.
- **One home per meaning, plain words, no history.** A rule lives in one place. A term is defined once. A doc says what to do, never what changed.
- **Portable.** A skill runs the same under Codex and Claude Code and depends on nothing outside its folder.
